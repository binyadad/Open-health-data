# Contributing

Suggestions, corrections and new sources are welcome.

To add or update a source, open an issue or a pull request with:

- the name of the source and a link to its official page
- the category it belongs to (see the Contents line in the README)
- a one-line description of the data it holds
- coverage, approximate size, access route and cost, where known

Entries follow this format:

```
- [Dataset Name](https://example.org/) - Short description of the data
  * Coverage: Country or region; Scale: Approximate size; Access: Access route; Cost: Free or fee
    + Optional note
```

Please link to the data provider rather than to news articles or third-party pages, and flag anything you could not verify.
